# Little Lemon — Лабораторна робота №6. Основи React Native

Перший екран мобільного застосунку на React Native + TypeScript (Expo).
Шапка й підвал залишаються на місці, прокручується лише середня частина.
Вміст не заходить під виріз, рядок стану та нижній індикатор.

## Запуск

```bash
npm install
npx expo start
```

Відкрийте QR-код в Expo Go (телефон і комп’ютер в одній мережі) або натисніть `a` / `i` для емулятора.

Перевірка типів (очікується відсутність помилок і код завершення 0):

```bash
npx tsc --noEmit
```

> Проєкт зібрано вручну за структурою шаблону `blank-typescript`, версії залежностей узято з демонстраційного проєкту.
> Якщо хочете створити «чистий» проєкт командою з методички, перенесіть у нього папки `components/`, `constants/` і файл `App.tsx`.
> Після цього виконайте `npx expo install react-native-safe-area-context`.

## Структура

```
little-lemon/
├── App.tsx                         # SafeAreaProvider, SafeAreaView, порядок: шапка → ScrollView → підвал
├── index.ts                        # реєстрація застосунку (не змінюємо)
├── constants/colors.ts             # палітра Little Lemon
└── components/
    ├── LittleLemonHeader.tsx       # шапка: назва й підзаголовок (props із типом)
    ├── WelcomeScreen.tsx           # привітання й 5 змістовних розділів
    └── LittleLemonFooter.tsx       # підвал: © {поточний рік} Little Lemon
```

Один компонент відповідає за одну частину екрана. Кожен має власний `StyleSheet.create`, inline-стилів немає.

## Як це влаштовано

- **Безпечна зона.** `SafeAreaProvider` + `SafeAreaView` з `react-native-safe-area-context` (не з `react-native`), `edges={['top','bottom']}`.
- **Прокручування середини.** Корінь має `flex: 1`; `ScrollView` теж `flex: 1` і лежить між шапкою та підвалом. Підвал стоїть після `</ScrollView>` і не використовує `position: 'absolute'`.
- **`style` і `contentContainerStyle`.** `style` задає саму прокручувану область (`flex: 1`), а `contentContainerStyle` — відступи всередині неї (`paddingBottom: 32`).
- **Індикатор.** `indicatorStyle="white"` працює на iOS; тло прокручуваної області темно-зелене, тому індикатор видно.
- **Контраст.** Білий текст на `#495E57` (≈ 7:1); темний `#333333` на світлих картках `#EDEFEE`. Акцентний `#EE9972` використано лише для великого заголовка.
- **Рік** обчислюється через `new Date().getFullYear()`.

## Відповіді на контрольні запитання

1. **`View`/`Text` проти `div`/тексту.** `View` — контейнер для структури й flexbox, але текст у ньому напряму розмістити не можна. Будь-який текст має бути в `<Text>`. Стилі задають JavaScript-обʼєктами через `style`, без CSS-селекторів, і вони не успадковуються від батька (колір треба вказати самому `Text`).
2. **Один кореневий елемент.** Компонент — функція, що повертає одне значення. Тому JSX має мати один корінь, який вміщує решту дерева. Тут це `SafeAreaProvider`.
3. **`SafeAreaProvider` / `SafeAreaView`.** Provider надає розміри безпечних меж (виріз, рядок стану, нижній індикатор). `SafeAreaView` додає відповідні відступи, щоб вміст не опинявся під системними елементами.
4. **`flex: 1`.** У корені: займи всю висоту екрана. У `ScrollView`: займи весь вільний простір між шапкою й підвалом. Завдяки обмеженій висоті працює прокручування, а підвал не виштовхується за екран.
5. **Підвал поза `ScrollView`.** Інакше він прокручувався б разом із текстом. Поза ним він має постійне місце в структурі екрана.
6. **`style` і `contentContainerStyle`.** `style` оформлює зовнішню прокручувану область (розмір, `flex`), а `contentContainerStyle` — внутрішній контейнер із вмістом (відступи, вирівнювання).
7. **`StyleSheet.create`.** Групує стилі за назвами й дає TypeScript перевірити властивості та значення. На відміну від CSS-файлу, це JS-обʼєкти: camelCase, числа без `px`, без селекторів і каскаду.
8. **TypeScript до запуску.** Невідповідність типів (наприклад, число замість `string` у props), відсутня обовʼязкова властивість, помилка в назві стилю чи властивості, неправильний імпорт.
9. **`FlatList` проти `ScrollView`.** `FlatList` — для великих або динамічних списків: він створює елементи по мірі потреби. `ScrollView` — для невеликого статичного вмісту, бо створює всі дочірні елементи одразу.

## Типові помилки, яких уникнуто

Текст без `Text`; підвал усередині `ScrollView`; `absolute` для підвалу; `SafeAreaView` з `react-native`; відсутній `flex: 1`; фіксована висота екрана в пікселях.
