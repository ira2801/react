# Лабораторна робота 5 — навігація і ресурси в React

React + TypeScript + React Router (декларативний режим). Сторінки: `/`, `/media`, `/about`, `/calculator`, `*` (404).

## Запуск
```bash
npm ci
npm run dev
```
Перевірка: `npm run build`, `npm run preview`.

Локальні зображення (`campus.svg`, `detail.svg`) — власні схеми. Зовнішні: фото Unsplash, відео Big Buck Bunny (YouTube).
